# SSC CGL Prep Tracker

A simple topic tracker to help track preparation progress for SSC CGL — Maths and Reasoning both covered.

## Features
- Topic-wise checklist for Maths and Reasoning
- Overall progress dial showing combined completion
- Separate progress tracking for each subject
- Clean dark UI with smooth animations
- Progress auto-saves in your browser

## How to use
1. Open `index.html` in any browser
2. Tap/click a topic once you've covered it
3. Track your progress with the progress bar and dial
4. Use the reset button if you want to start fresh

## Note
Progress is saved locally in your browser (using localStorage), so it stays only on the device/browser you use it in.
