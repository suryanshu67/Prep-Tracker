# SSC CGL Prep Tracker

A simple topic tracker to help track preparation progress for SSC CGL — Maths and Reasoning both covered.

## Features

- Topic-wise checklist for Maths and Reasoning
- Overall progress dial showing combined completion
- Separate progress tracking for each subject
- Personalized with your name — asks once, then greets you by name every time
- Share My Progress — generates a read-only snapshot link of your current progress to send to anyone
- Clean dark UI with smooth animations and a subtle twinkling star background
- Progress auto-saves in your browser

## How to use

1. Open `index.html` in any browser
2. Enter your name when prompted (only asked once)
3. Tap/click a topic once you've covered it
4. Track your progress with the progress bar and dial
5. Use the reset button if you want to start fresh
6. Click **Share My Progress** to copy a snapshot link — anyone who opens it sees your progress exactly as it was at that moment (read-only, doesn't update live)

## Note

Progress and your name are saved locally in your browser (using localStorage), so they stay only on the device/browser you use. A shared snapshot link is frozen at the time it was generated — track new progress and you'll need to share a fresh link.
